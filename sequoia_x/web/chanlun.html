这些术语怎么看？
分型三根合并K线形成的局部顶或底，需要右侧K线才能确认。
笔满足最小间距的顶、底分型连接。箭头表示方向，日期是两个端点。
中枢至少三笔共同覆盖的价格区间；ZG/ ZD 是重叠区上下沿，GG/DD 是整体最高和最低。
线段由若干笔组合出的更高一级结构。当前实现是程序化简化识别。
买卖点1/2/3 类表示背驰转折、首次回调和突破后回踩。当前模块有时间错配风险。
背驰当前实现主要比较两笔价格振幅，并非完整MACD面积判断，只适合研究。
数据仅在本机浏览器与本地 Python 服务之间传输。结构研究结果不代表交易建议。
